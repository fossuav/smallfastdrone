# SmallFastDrone architectural rules

Rules that hold on the SmallFastDrone branches and not upstream: the
assumptions the SFD code makes about how its pieces fit together, usually
because the branch carries PRs that master does not. Read the ones whose
scope a change touches, alongside the playbook for that code. `/pr-review`
holds changes against them.

Every rule here was confirmed by the user. Candidates wait in
`RULES_PROPOSED.md` beside this file and are not standards until they move
here. Rules that hold on master belong in the `aap` playbooks, not here;
when an upstream merge makes an SFD rule true of master, move it there.
